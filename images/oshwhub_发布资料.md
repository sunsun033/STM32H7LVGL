```markdown
## 一、项目简介

这是一块围绕「RGB-LCD 图形界面」场景设计的 STM32H743 开源开发板。

画这块板的初衷很实际：STM32H7 性能强，但想跑好一套 GUI，你必须同时解决三件事——**足够大的显存（SDRAM）、够用的存储（Flash + TF）、以及正确的 RGB 屏时序**。市面上很少有板子把这三样一次配齐，往往要自己飞线。所以我把它们做到了一块 60mm 见方的小板上，从硬件到驱动全部验证完毕再开源。

**一句话总结：到手即用的 H743 图形界面开发平台。**

## 二、功能特性

| 外设 | 型号 / 规格 | 实测状态 |
| --- | --- | --- |
| 主控 | STM32H743VIT6（LQFP144，Cortex-M7 @480MHz） | ✅ |
| SDRAM | W9825G6KH-6（Winbond，TSOP54，32MB） | ✅ 120MHz 下 MemTest **0 错误** |
| RGB-LCD | RGB565 接口，40pin FPC | ✅ LVGL 稳定 **59~60 FPS**，CPU 占用约 1% |
| 电容触摸 | TP 接口（I2C） | ✅ |
| SPI Flash | Winbond WSON8 | ✅ 读写正常 |
| TF 卡 | 卡座 | ✅ 读写正常 |
| 调试接口 | Type-C（DEBUG，供电 + USB 转串口） | ✅ |
| 串口 | Type-C（UART） | ✅ |
| 按键 | USER / RST / BOOT0 | ✅ |
| 指示灯 | POWER LED / SLED（串口状态） | ✅ |
| 扩展接口 | 2.54mm 双排排针（GPIO + 3.3V/5V/GND） | ✅ |

### 亮点说明

**1. SDRAM 跑在 120MHz，实测零错误**

SDRAM 用了 Winbond W9825G6KH-6（32MB）。这块片子标称 166MHz，我把它稳定跑到 120MHz 并长时间跑 MemTest，结果为 0 错误。这意味着你有充足的余量把 SDRAM 当显存用——LVGL 的多缓冲、全屏刷新都不再是瓶颈。

**2. LVGL 稳定 60 帧**

左上角可以看到 LVGL 的性能监视器：`59 FPS, 1% CPU, 3ms`。60Hz 是 RGB 屏的刷新上限，也就是说这块板子的刷屏能力已经**跑满屏的极限**，CPU 还几乎没占用，剩下的算力全都可以留给你的业务逻辑。

**3. 外设全部实测通过，不是「理论可用」**

所有外设都在实物上验证过，不是画完图就开源。配套白色 3D 打印外壳，装好就是一整机。

## 三、硬件设计说明

- **主控**：STM32H743VIT6，LQFP144 封装，480MHz Cortex-M7，双精度浮点
- **SDRAM 布线**：TSOP54 封装，注意等长与时钟线处理，保证 120MHz 下的信号完整性
- **显示接口**：40pin FPC 座，RGB565 直驱；背面预留 TP 触摸座（I2C）
- **供电**：Type-C 输入，板载 5V/3.3V 转换，带钽电容滤波
- **扩展**：右侧双排 2.54mm 排针，引出常用 GPIO 及 3.3V / 5V 供电

### GPIO 扩展口丝印

```
GND  3V   A13  A14  5V   A12  A11  C9   C8   C0
C6   C7   D13  D12  D11  B11  B10  C3   C2   C4
C5   A7   H3   H4   E6   ...
```

> 完整引脚分配以原理图为准。

## 四、实物验证

外壳为 3D 打印，装上后是一台完整的桌面小终端。图片见下方附件与工程图库。

**演示内容**：LVGL 完整 UI 演示（图像显示 + 亮度调节控件），全程稳定 59~60 FPS。

## 五、软件说明

- **开发环境**：Keil MDK / STM32CubeIDE（固件源码见附件）
- **图形库**：LVGL
- **BSP 驱动**：SDRAM、RGB-LCD、电容触摸、SPI Flash、TF 卡（FatFs）
- **上手流程**：
  1. Type-C 线接 `DEBUG` 口供电（同时可用作串口调试）
  2. 按住 `BOOT0` + 按一下 `RST` 可进入系统 Bootloader，实现串口下载
  3. 上电自动运行 LVGL 演示程序
  4. 二次开发直接基于 BSP 添加应用即可

## 六、注意事项 / 已知问题

1. RGB 屏为 **RGB565** 接口、40pin FPC，更换屏幕需按新屏时序修改 LCD 驱动参数
2. SDRAM 时钟设定为 120MHz，如需更高频率请自行验证信号完整性
3. 扩展口 IO 为 **3.3V 电平**，不可直接驱动 5V 器件或大电流负载
4. 触摸芯片型号请对照原理图 TP 部分标注
```

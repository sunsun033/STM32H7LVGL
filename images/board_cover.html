🧠

STM32H743 主控

Cortex-M7 双精度浮点，480MHz 主频，2MB Flash / 1MB RAM，性能拉满的 MCU 平台。

🖥️

RGB-LCD + 触摸

标准 RGB FPC 接口与触摸接口（TP），直驱大屏，跑 LVGL / TouchGFX 毫无压力。

💾

三重存储

板载 SDRAM（帧缓冲专用）+ WSON8 SPI Flash + TF 卡座，Bootloader、资源文件、日志各得其所。

🔌

Type-C 调试

Debug Type-C 一线连接，板载电源指示 LED 与串口状态 LED，调试体验清爽利落。

🔘

用户按键

RST / BOOT0 / 用户按键三键齐备，ISP 下载与功能触发无需镊子短接。

📌

双排扩展 IO

3.3V / 5V 电源轨 + 全部关键 GPIO 引出，接传感器、模块、逻辑分析仪都很顺手。
